# Audio Lab

Source-safe audio inventory, evidence validation, runtime-reference audit, and review tooling for OpenAzrael.

Start with:

    python tools/audio_lab/oa_audio_scan.py /path/to/source-audio
    python tools/audio_lab/oa_audio_validate.py .tmp/audio_lab/al_poc_01/audio_manifest.json --source-root /path/to/source-audio

See docs/AUDIO_LAB_AL_POC_01.md for the contract and acceptance gates.
