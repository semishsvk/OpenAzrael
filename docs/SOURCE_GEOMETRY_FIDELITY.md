# Source Geometry Fidelity Policy

## Status

**NON-NEGOTIABLE / FAIL-CLOSED**

OpenAzrael must reproduce every playable room from the original Azrael's Tear geometry. A room is not acceptable merely because it is traversable, visually plausible, or topologically similar.

## Canonical rule

For every demo or retail room included in a runnable build:

1. The room geometry must be derived from the original game/demo source geometry.
2. The complete authored room must be imported. Partial-room imports are release blockers.
3. No architectural geometry may be invented, approximated, simplified, reconstructed by eye, procedurally substituted, or generated by AI.
4. Missing source geometry must produce **BLOCKED_MISSING_SOURCE_GEOMETRY** or FAIL. It must never fall back to placeholder geometry in a runnable build.
5. Original object membership, transforms, mesh topology and room-space placement must be preserved unless a transformation is explicitly documented as a reversible engine-coordinate conversion.
6. Gameplay collision may be derived from the authored visible geometry, but invisible replacement floors/walls must not be used to conceal missing authored geometry.
7. Rendering fixes may correct engine compatibility (materials, alpha semantics, winding, normal handling, texture decoding) without changing the authored shape.
8. State-dependent rooms must preserve each original authored geometry state independently. One state must not be fabricated from another.
9. Documentation/topology diagrams may use schematic nodes for unavailable retail geometry only when clearly marked as schematic. Such placeholders must never enter runtime room assets.
10. A Candidate build may not export unless source-geometry parity passes for every room included in that Candidate.

## Retail rule

Retail rooms may enter runtime only after their original retail XAF/room geometry
has been recovered and bound to a canonical room/state with evidence. Until then
the room is **not implemented**, not approximated.

A retail topology map may show a room whose geometry is unavailable, but it must
be represented only as an explicitly schematic/topological node.

## Acceptance

Geometry parity is a release invariant, not a cosmetic QA item. Any missing,
extra, substituted, or invented room geometry is a **critical build defect** and
blocks KG / release promotion.
